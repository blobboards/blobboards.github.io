BlobBoards

Robust Markers for Accurate Pose

James Pritts, Till Sittart, Hendrik Sauer, Silja Janßen, Felix Seegräber, David Nakath, Kevin Köser Marine Data Science Kiel University · BMVC 2026

Abstract

We propose BlobBoards, a fiducial marker system comprising a dense, multi-scale field of Gaussian blobs and a feature-based pipeline for joint detection, identification, and pose estimation. Each board is registered from hundreds of blob features whose dense spatial coverage constrains pose, while multiple scales preserve detectability across large changes in focal length, distance, and obliquity. Learned local descriptors are matched to the reference pattern and spatially verified, so the correspondences determine pose and certify identity. Against motion-capture ground truth, BlobBoards achieve median translation errors of 3.6–5.0 mm, reducing AprilTag's median translation error by 89% on small boards and 70% on large ones. They also produce far fewer large-rotation failures than state-of-the-art tag systems. BlobBoards achieve the highest detection rate, 80% versus 74% for AprilTag and 58% for ArUco, with the largest margin on the smallest markers. Under 50% occlusion, they still detect 69% of boards with essentially unchanged median translation error, while AprilTag and ArUco detect none.

Install

Copy the command for your language and install method.

Julia

pixi — installs Julia, Python and Ghostscript and resolves the package environment; then using BlobBoards:

git clone https://github.com/prittjam/BlobBoards.jl && cd BlobBoards.jl && pixi install && pixi run julia --project=.

Pkg — BlobBoards is published in CauRegistry, not General (Julia 1.12+; Ghostscript for PDF compression):

using Pkg; Pkg.Registry.add(RegistrySpec(url = "git@github.com:prittjam/CauRegistry.jl.git")); Pkg.add("BlobBoards")

Python

pixi — installs the blobboards Python package together with the Julia core; the example writes an A4 board to ./output:

git clone https://github.com/prittjam/BlobBoards.jl && cd BlobBoards.jl && pixi install && pixi run python python/examples/boards/generate_a4_board.py

pip — installs blobboards with its juliacall and numpy dependencies into your current Python environment:

git clone https://github.com/prittjam/BlobBoards.jl && cd BlobBoards.jl/python && pip install -e .

Getting started

Install BlobBoards and generate, print and detect your first board in Getting Started. Authoring boards covers the authoring environment, every board option and printing; Detecting boards covers find_boards, pose estimation and GPU acceleration. The Overview introduces patterns, boards and the coordinate conventions.

using BlobBoards, CairoMakie   # CairoMakie loads the board-authoring extension# A4 board at 300 dpi, smallest printed disc 4 mm across → board PDF + JSON in ./outblob_board("A4", 300dpi; blob_sizes = (4.0mm, nothing), seed = 0xBEEF, dir = "./out")# Or a pixel pattern for simulation and trainingblob_pattern(800, 600; blob_sizes = (12px, nothing), seed = 0x1234, dir = "./out")

Method

A board is registered from hundreds of blob features, not from four corners — that is where the accuracy and the occlusion robustness come from.

(a)(b)(c)(d)

(a) Detect: affine detections from the ASIFT scale space. (b) Adapt: IRLS adaptation to anisotropic ellipses; the twelve pose inliers are coloured individually. (c) Canonicalize: those inliers mapped to 64×64 log-polar patches. (d) Match & verify: descriptors matched and spatially verified; the pattern projected under the recovered pose, with reference blob centres in green at opacity proportional to their geometric consistency.

  • Generate. A seeded pattern packs blobs from several octaves of scale into one field. The same seed reproduces the same board, in Julia or Python.
  • Adapt and register. Each detected blob gets a fitted elliptical frame, is canonicalized into a patch, and described by a learned log-polar network. Matches to the reference pattern are spatially verified, so the correspondences determine pose and certify identity.
  • Evaluate. Poses are scored against motion-capture ground truth on a rig of boards at a range of sizes, distances, and angles, alongside AprilTag and ArUco.

Data & models

The paper's data is frozen on Zenodo; the networks and example data the package ships live on Hugging Face.

  • Reproducing the BMVC results. Everything the paper's numbers were computed from is archived at doi:10.5281/zenodo.21998311: the absolute-pose captures with camera calibrations, motion-capture ground truth and hand-eye calibrations; the AprilTag and ArUco baseline detections; the 0–90% occlusion series; the frozen descriptor training set; and the network the reported poses were produced with. It is packaged as sha256-pinned Julia artifact tarballs that bmvc2026/Artifacts.toml fetches lazily.
  • Production networks. blobboards-descriptor holds the ONNX descriptor networks; the package's Artifacts.toml is an add-only, commit-pinned catalog of them. blobboards-examples holds the boards, still image and video the bundled examples run on.
