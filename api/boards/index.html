Coordinate Functions

Coordinate transforms are extensions of the CoordinateTransformations constructors:

# Reference-frame translations (within the board layout)T = Translation(board_config, :pattern, :canvas)   # BoardConfig: :pattern/:board/:canvas# Coordinate-system transforms (pixel ↔ physical ↔ world)H = AffineMap(bundle, :logical, :world)            # :logical/:physical/:world# Image-origin conventions (from VisualGeometryCore)T_origin = Translation(:colmap, :julia)            # :colmap/:julia/:opencv# Compose freelyT_full = Translation(:colmap, :julia) ∘ Translation(board_config(bundle), :pattern, :canvas)

See also Public API for blobs (including blobs(bundle, :world)) and saddle_points.
