File Naming

BlobBoards.make_filebase — Function
make_filebase(bundle::AbstractBundle; config_hash = hash_config(…)) -> String

Base filename (without extension) computed from the bundle type and configuration hash. Returns "blobboard<hash>" for BoardBundle and "blobpattern<hash>" for PatternBundle, where <hash> is the first 8 characters of the hex-encoded SHA-256 hash of the complete configuration, formatted as XXX_XXXXX (3 chars underscore 5 chars) for readability.

For BoardBundle: hash is SHA-256 of preamble (PatternConfig + BoardConfig) For PatternBundle: hash is SHA-256 of PatternConfig. A bundle loaded from disk must be given its stored config_hash (hashes.config), its identity.
