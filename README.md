# blobboards.github.io

Project site for [BlobBoards](https://github.com/prittjam/BlobBoards.jl) —
*BlobBoards: Robust Markers for Accurate Pose*, BMVC 2026.

Static HTML, served by GitHub Pages from the root of this repository.
`index.html` and `images/` are authored directly here; commits to `main`
deploy the site.

`template.html` is a content-free copy of the page — same CSS, JS, and
components with placeholder text. To start a new project site, copy it to a
new repo as `index.html` and work through the `TODO` markers.
